📱 สแกนสลิปด้วย iPhone

ติดตั้งครั้งเดียวประมาณ 3 นาที ไม่ต้องสร้างคำสั่งลัด หลังจากนั้นโอนเงินเสร็จ แตะไอคอนเดียวก็บันทึกได้

ก่อนเริ่มต้องมี
  • ติดตั้งแอป Scriptable แล้ว และเคยรันโค้ดติดตั้ง Widget มาแล้ว (ส่วนที่ 1 ด้านล่างจะติดตั้งสคริปต์สแกนสลิปให้ด้วยในขั้นตอนเดียวกัน)
  • รหัสของคุณจะถูกเก็บไว้ในมือถือโดยตัวติดตั้งให้เอง ไม่ต้องกรอกอะไรเพิ่ม

ส่วนที่ 1: ติดตั้งสคริปต์ลงมือถือ

  1. ในหน้า "ตั้งค่า iPhone" บนเว็บ กด "สร้างรหัสสำหรับเครื่องนี้" โค้ดติดตั้งจะถูกคัดลอกให้อัตโนมัติ
  2. เปิดแอป Scriptable → เปิดสคริปต์ DeptInstaller ตัวเดิม (หรือกด + สร้างใหม่) → ลบโค้ดเก่าทั้งหมด → วางโค้ดใหม่ → กด ▶
  3. ต้องขึ้น "ติดตั้งสำเร็จ ✅" และในรายการสคริปต์จะมี DeptWidget กับ DeptSlip เพิ่มขึ้นมา

ส่วนที่ 2: ตั้งไอคอนบนหน้าจอโฮม (ทำครั้งเดียว)

  1. เปิดแอป Scriptable → แตะสคริปต์ DeptSlip เพื่อเปิดขึ้นมา
  2. แตะปุ่ม ตั้งค่า ของสคริปต์ (ไอคอนปุ่มเลื่อน ด้านล่างหรือมุมขวา) → เลือก Add to Home Screen (เพิ่มลงหน้าจอโฮม)
  3. ตั้งชื่อไอคอนว่า สแกนสลิป แล้วเพิ่มลงหน้าจอโฮม (ชื่อปุ่มอาจต่างเล็กน้อยตามเวอร์ชัน ถ้าหาไม่เจอให้บอกผู้พัฒนา)

ส่วนที่ 3: วิธีใช้ทุกครั้งที่จ่ายเงิน

  1. โอนเงินเสร็จ → แคปหน้าจอสลิป (หรือกดบันทึกสลิปลงรูปภาพจากแอปธนาคาร)
  2. แตะไอคอน สแกนสลิป บนหน้าจอโฮม → แอป Scriptable เปิดขึ้นมา รอประมาณ 3–10 วินาที (ระบบกำลังอ่านสลิป)
    ครั้งแรกจะถามสิทธิ์เข้าถึงรูปภาพ ให้กด อนุญาตให้เข้าถึงทุกรูปภาพ
  3. จะเห็นกล่อง "🧾 พบบิล ฿xxx" ให้เลือก 👤 ส่วนตัว หรือ 👥 หารกับเพื่อน
ถ้าเลือก "หารกับเพื่อน"
  • แตะชื่อเพื่อนเพื่อเลือก (เลือกได้หลายคน) แตะซ้ำเพื่อยกเลิก แล้วกด ✔︎ เสร็จ
  • เลือกชื่อตัวเอง (⭐ ... (ฉัน)) = หารรวมตัวเองด้วย
  • ไม่เลือกชื่อตัวเอง = จ่ายแทนเพื่อน (ไม่มีส่วนของตัวเอง เพื่อนที่เลือกค้างคุณคนละเท่าๆ กัน)
  • ต้องเลือกเพื่อนอย่างน้อย 1 คน
อีกวิธี: เปิดรูปสลิปในแอปรูปภาพ → แตะปุ่มแชร์ → เลือก Run Script (Scriptable) → เลือก DeptSlip
รูปสลิปจะถูกส่งให้ AI (Google Gemini) อ่านยอดเงิน ระบบ Dept Money ไม่เก็บรูปไว้ เก็บเฉพาะยอด ผู้รับ และเลขอ้างอิง

ทางเลือก: ให้เด้งอัตโนมัติเมื่อปิดแอปธนาคาร (ไม่บังคับ)

ถ้าไม่อยากแตะไอคอนเอง ตั้งให้เด้งขึ้นมาทุกครั้งที่ปิดแอปธนาคารได้ แต่ต้องสร้างคำสั่งลัดเพิ่ม (ประมาณ 5 นาที)

แสดงวิธีตั้งแบบอัตโนมัติ

คำสั่งลัดแบบ 3 คำสั่ง

เปิดแอป คำสั่งลัด (Shortcuts) → แตะ + → ตั้งชื่อว่า สแกนสลิป → ค้นหาคำสั่งตามชื่อข้างล่าง (ถ้าค้นชื่อไทยไม่เจอ ให้ลองคำในวงเล็บ)

  1. ค้นหารูปภาพ (Find Photos)
    ตัวกรอง: วันที่สร้าง → อยู่ใน → 5 → นาที / จัดเรียง: วันที่สร้าง ล่าสุดก่อน / เปิด จำกัด 1 รายการ
  2. ถ้า (If)
    เงื่อนไข: รูปภาพ → มีค่าใดๆ (has any value)
  3. เรียกใช้สคริปต์ (Run Script — ของแอป Scriptable)
    สคริปต์: DeptSlip · ช่องข้อมูลนำเข้า/Input: เลือกตัวแปร รูปภาพ (จากขั้นที่ 1)

แอปจะเติม "จบ If" ให้เอง

ตั้งให้ทำงานเมื่อปิดแอปธนาคาร

  1. ในแอปคำสั่งลัด ไปแท็บ การทำงานอัตโนมัติ → + → แอป
  2. เลือกแอปธนาคารที่ใช้ (K PLUS, SCB EASY, ttb touch, Krungthai NEXT, UOB TMRW, Kept ฯลฯ) → ติ๊ก ถูกปิด
  3. เลือกคำสั่งลัด สแกนสลิป → เลือก รันทันที → ปิด แจ้งเตือนเมื่อทำงาน
วิธีใช้งานจริง: โอนเงินเสร็จ → แคปสลิปหรือบันทึกสลิปลงรูปภาพ → ปิดแอปธนาคาร → กล่องถามจะเด้งขึ้นมาเอง
ทางเลือก: แบบละเอียด (ไม่เปิดแอป Scriptable ขึ้นมาบัง แต่ต้องสร้างหลายคำสั่งและวางรหัสเอง)

แบบนี้ต้องกดปุ่ม "คัดลอกรหัส" ในหน้า "ตั้งค่า iPhone" ไว้ก่อน แล้ววางรหัสในขั้นที่ 1 ของคำสั่งลัด

เปิดแอป คำสั่งลัด (Shortcuts) → แตะ + → ตั้งชื่อว่า สแกนสลิป → แตะ "เพิ่มการทำงาน" แล้วค้นหาชื่อคำสั่งตามข้างล่าง (ถ้าค้นชื่อไทยไม่เจอ ให้ลองคำในวงเล็บ)

  1. ข้อความ (Text)
    แตะในช่องข้อความ แล้ววางรหัสที่คัดลอกมา จะเห็นเป็น Bearer ตามด้วยตัวอักษรยาวๆ
  2. ตั้งค่าตัวแปร (Set Variable)
    ตั้งชื่อตัวแปรว่า รหัส
  3. ค้นหารูปภาพ (Find Photos)
    แตะ "เพิ่มตัวกรอง" แล้วตั้งค่า:
    • วันที่สร้าง → อยู่ใน → 5 → นาที (ล่าสุด 5 นาที)
    • จัดเรียงตาม: วันที่สร้าง / ลำดับ: ล่าสุดก่อน
    • เปิด จำกัด → 1 รายการ
    ทำไมต้อง 5 นาที: ถ้าไม่มีสลิปใหม่ คำสั่งลัดจะไม่ทำอะไร และไม่ถามซ้ำทุกครั้งที่เปิด–ปิดแอปธนาคาร
  4. ถ้า (If)
    ตั้งเงื่อนไข: รูปภาพ (ผลลัพธ์จากขั้นที่ 3) → มีค่าใดๆ (has any value)
    ขั้นที่ 5 ถึง 11 ต้องอยู่ "ภายใน" ถ้านี้ ทั้งหมด
  5. แยกข้อความจากรูปภาพ (Extract Text from Image)
    ข้อมูลนำเข้า: รูปภาพ จากขั้นที่ 3
  6. รับเนื้อหาของ URL (Get Contents of URL)
    ช่องค่า
    URLhttps://dept-game.vercel.app/api/shortcut-transaction
    วิธีแตะ "แสดงเพิ่มเติม" → วิธี: POST
    ส่วนหัวเพิ่มส่วนหัว: ชื่อ Authorization ค่า = ตัวแปร รหัส (แตะช่องค่า แล้วเลือกตัวแปร "รหัส")
    เนื้อหาคำขอJSON แล้วกด "เพิ่มช่องใหม่" 2 ช่อง (ชนิด ข้อความ ทั้งคู่):
    • คีย์ action ค่า parse
    • คีย์ text ค่า = ตัวแปร ข้อความจากรูปภาพ (ผลจากขั้นที่ 5)
  7. รับค่าพจนานุกรม (Get Dictionary Value)
    รับ ค่า สำหรับคีย์ message ใน เนื้อหาของ URL (ผลจากขั้นที่ 6)
  8. เลือกจากเมนู (Choose from Menu)
    • ข้อความแจ้ง (Prompt): แตะแล้วเลือกตัวแปร ค่าพจนานุกรม (ผลจากขั้นที่ 7)
    • ตัวเลือก 3 อัน ตั้งชื่อตามนี้: 👤 ส่วนตัว   👥 หารกับเพื่อน   ❌ ปิด
    หลังเพิ่มแล้ว จะมี 3 ช่องว่างให้ใส่คำสั่ง ทำตามขั้นที่ 9, 10, 11
  9. ใต้ตัวเลือก "👤 ส่วนตัว" — เพิ่ม 3 คำสั่งต่อไปนี้:
    ① รับเนื้อหาของ URL: URL เดิม, วิธี POST, ส่วนหัว Authorization = รหัส, เนื้อหา JSON 2 ช่อง:
      • action = save
      • splitType = personal
    ② รับค่าพจนานุกรม: คีย์ message
    ③ แสดงผลลัพธ์ (Show Result)
  10. ใต้ตัวเลือก "👥 หารกับเพื่อน" — เพิ่ม 6 คำสั่งต่อไปนี้:
    ① รับเนื้อหาของ URL: URL https://dept-game.vercel.app/api/get-members?include_self=1 วิธี GET ส่วนหัว Authorization = รหัส (ไม่มีเนื้อหา)
    ② รับค่าพจนานุกรม: คีย์ members
    ③ เลือกจากรายการ (Choose from List): เปิด เลือกหลายรายการ (Select Multiple), ข้อความแจ้ง: เลือกคนที่หารด้วย
    ④ รับเนื้อหาของ URL: URL https://dept-game.vercel.app/api/shortcut-transaction วิธี POST ส่วนหัว Authorization = รหัส เนื้อหา JSON 3 ช่อง (ชนิดข้อความ):
      • action = save
      • splitType = equal
      • splitWith = ตัวแปร รายการที่เลือก (Chosen Items) จาก ③
    ⑤ รับค่าพจนานุกรม: คีย์ message
    ⑥ แสดงผลลัพธ์
  11. ใต้ตัวเลือก "❌ ปิด" — ไม่ต้องเพิ่มอะไร
ถ้าตอนเลือกรายการ เห็นชื่อตัวเองอยู่บนสุดมีดาว ⭐ และ "(ฉัน)"
  • ติ๊กชื่อตัวเอง = หารรวมตัวเองด้วย (เช่น กินข้าวด้วยกัน)
  • ไม่ติ๊กชื่อตัวเอง = จ่ายแทนเพื่อน (ไม่มีส่วนของตัวเอง เพื่อนที่เลือกค้างคุณคนละเท่าๆ กัน)
  • ต้องเลือกเพื่อนอย่างน้อย 1 คน

เสร็จแล้วแตะ เสร็จสิ้น เพื่อบันทึกคำสั่งลัด

แก้ปัญหา

ขึ้นว่า "ไม่พบรูปสลิป" หรือขอสิทธิ์รูปภาพ

แคปสลิปไว้ก่อนแล้วเปิดใหม่ และตรวจสิทธิ์ที่ ตั้งค่า → Scriptable → รูปภาพ → เลือก ทุกรูปภาพ

ขึ้นว่า "อ่านรูปสลิปไม่สำเร็จ"

ระบบ AI ไม่ตอบสนองชั่วคราว ลองแตะไอคอนใหม่อีกครั้งในอีกสักครู่ ถ้าเกิดซ้ำหลายครั้งให้แจ้งผู้พัฒนา

ยอดหรือชื่อผู้รับอ่านผิด

แจ้งผู้พัฒนาพร้อมระบุธนาคารของสลิป (ถ่ายภาพสลิปที่ลบชื่อและเลขบัญชีแล้วได้) เพื่อปรับให้อ่านถูกต้องขึ้น

ขึ้นว่า "รหัสไม่ถูกต้อง" หรือ "รหัสถูกยกเลิก"

รหัสถูกสร้างใหม่ทับ หรือถูกยกเลิก กลับไปหน้า "ตั้งค่า iPhone" กดสร้างรหัสใหม่ แล้วรันโค้ดติดตั้งซ้ำ 1 ครั้ง (แบบง่ายแค่นี้พอ) ส่วนแบบละเอียดต้องแก้ขั้นที่ 1 ในคำสั่งลัดให้เป็นรหัสใหม่ด้วย

Scriptable ขึ้นว่า "ยังไม่ได้ตั้งค่ารหัสอุปกรณ์"

ยังไม่เคยรันโค้ดติดตั้ง หรือรันแล้วไม่สำเร็จ กลับไปทำส่วนที่ 1 ให้ขึ้นว่า "ติดตั้งสำเร็จ"

Scriptable ขึ้นว่า "ไม่ได้รับข้อความจากคำสั่งลัด"

ตรวจว่าคำสั่ง "เรียกใช้สคริปต์" ส่งตัวแปร "รูปภาพ" ให้สคริปต์ DeptSlip และอยู่ภายใน "ถ้า"

ขึ้นว่า "ไม่พบยอดเงินในรูปล่าสุด"

ระบบจะบอกว่าอ่านข้อความอะไรได้จากรูป ถ้าเป็นสลิปจริงแต่อ่านไม่ได้ ให้คัดลอกข้อความที่ขึ้นแสดง (ลบเลขบัญชีและชื่อออกก่อนก็ได้) ส่งให้ผู้พัฒนา เพื่อปรับให้อ่านสลิปธนาคารนั้นได้

ขึ้นว่า "สลิปนี้เคยบันทึกแล้ว"

เป็นปกติ ระบบกันบันทึกสลิปใบเดิมซ้ำ กดปุ่ม ❌ ปิด ได้เลย

ไม่มีอะไรเด้งขึ้นมาเลยหลังปิดแอปธนาคาร

(เฉพาะแบบอัตโนมัติ) เป็นปกติถ้าไม่มีรูปใหม่ภายใน 5 นาที ให้แคปสลิปก่อนปิดแอป และตรวจว่าเลือกแอปธนาคารถูกตัว

เมนูหารเพื่อนไม่เห็นชื่อเพื่อน

ตรวจ (เฉพาะแบบละเอียด) ว่าขั้นที่ 10 ① ใช้ URL ที่ลงท้ายด้วย ?include_self=1 และส่วนหัว Authorization ใช้ตัวแปร "รหัส"
