ตั้งค่า iPhone ให้บันทึกรายจ่ายเอง

อัปเดต 18 พ.ย. 2569 · ใช้กับสคริปต์ DeptAuto รุ่น 2.0.0 · ทำครั้งเดียวประมาณ 10 นาที

ใช้งานจริงเป็นแบบนี้
1. จ่ายเงินตามปกติ (โอนแล้วแคปสลิป, รูดบัตรแล้วมี SMS หรืออีเมลจากธนาคาร)
2. iPhone เด้งแจ้งเตือน "พบรายจ่าย ..." แตะที่แจ้งเตือน (หรือกดค้างแล้วกด แก้ไข)
3. แอป Scriptable เปิดกล่องขึ้นมา แก้ชื่อรายการได้ กด เปลี่ยนหมวด ได้
4. กด บันทึกส่วนตัว (เสร็จเลย) หรือ หารกับเพื่อน (เปิดเว็บให้เลือกเพื่อน) หรือ ไม่ใช่รายจ่าย (ลบ)

ชื่อที่แก้ ระบบจำไว้ ครั้งหน้าจ่ายร้านเดิมจะได้ชื่อและหมวดนั้นเอง · ถ้าไม่กดอะไร ระบบเก็บเป็นรายจ่ายส่วนตัวไว้ให้ และในเว็บจะมีป้าย ยังไม่ยืนยัน

1ติดตั้งสคริปต์

  1. ติดตั้งแอป Scriptable จาก App Store (ฟรี)
  2. เปิดเว็บ Dept Money → แท็บ ฉัน → ตั้งค่า iPhone → กด สร้างรหัสและคัดลอกสคริปต์
  3. เปิด Scriptable → กด + → ลบข้อความเดิม แล้ว วาง → กดปุ่ม เล่น (สามเหลี่ยม)
  4. ขึ้น ติดตั้งสำเร็จ และเห็น DeptWidget กับ DeptAuto v2.0.0
    ถ้ามีหน้าต่าง "พบสคริปต์ Dept ที่ไม่ใช้แล้ว" กด ลบทั้งหมด

ครั้งแรกที่ระบบจะเด้งแจ้งเตือน iPhone จะถามว่าให้ Scriptable แจ้งเตือนได้ไหม ให้กด อนุญาต

2สร้างคำสั่งลัด "Dept บันทึก"

คำสั่งลัดเดียว ใช้ได้ทั้งสลิป SMS และอีเมล ไม่ต้องใส่คำสั่งแสดงการแจ้งเตือน เพราะ DeptAuto เด้งให้เอง

  1. เปิดแอป คำสั่งลัด → แท็บ คำสั่งลัด → + → ตั้งชื่อ Dept บันทึก
  2. ถ้า (If) เลือก ข้อมูลเข้าของคำสั่งลัด → มีค่าใดค่าหนึ่ง
    ด้านบนจะมีการ์ด "รับ ... จาก ไม่มีที่ไหน" โผล่มาเอง ไม่ต้องแก้
  3. Run DeptAuto with (Run Script ของ Scriptable) ช่องหลังเลือก ข้อมูลเข้าของคำสั่งลัด
    แตะลูกศรวงกลมท้ายแถว แล้วปิด Run In App และ แสดงเมื่อสั่งทำงาน
  4. มิฉะนั้น (Otherwise) แล้วใส่ 3 คำสั่งต่อไปนี้ใต้คำว่ามิฉะนั้น
  5. รับรูปภาพล่าสุด จำนวน 1 และเปิด รวมภาพถ่ายหน้าจอ
  6. แยก ข้อความ ออกจาก รูปภาพล่าสุด
  7. Run DeptAuto with ช่องหลังเลือก ข้อความที่แยกออก แล้วปิด Run In App และ แสดงเมื่อสั่งทำงาน เหมือนข้อ 3
  8. สิ้นสุดถ้า (แอปเติมให้เอง)

3ตั้งให้ทำงานเอง

แอปคำสั่งลัด → แท็บ การทำงานอัตโนมัติ → + ทำเฉพาะแบบที่ใช้ ทุกแบบเลือก รันทันที และมีคำสั่งเดียวคือ เรียกใช้คำสั่งลัด Dept บันทึก

แบบ A: ปิดแอปธนาคาร (สลิปโอนเงิน)

  1. เลือก แอป → เลือกแอปธนาคารที่ใช้ (เลือกได้หลายแอป) → ติ๊ก ถูกปิด → รันทันที
  2. เพิ่มคำสั่ง เรียกใช้คำสั่งลัด → เลือก Dept บันทึก

แบบ B: SMS บัตรเครดิต (KTC, CardX, ttb)

  1. เลือก ข้อความ → ข้อความประกอบด้วย พิมพ์ THB → รันทันที
  2. เพิ่มคำสั่ง เรียกใช้คำสั่งลัด → เลือก Dept บันทึก แล้วตั้งข้อมูลเข้าเป็น ข้อมูลเข้าของคำสั่งลัด
ถ้าด้านบนขึ้นว่า กำหนดค่า "ผู้ส่ง" เพื่อเปิดใช้งาน ให้กดปุ่มลบที่ท้ายแถว "ผู้ส่ง คือ" ถ้ายังเปิดใช้ไม่ได้ ให้ทำแบบ B แยกทีละผู้ส่ง (KTC, CardX, ttbbank) (ส่วนนี้ยังอยู่ระหว่างทดสอบบนเครื่องจริง)

แบบ C: อีเมลจากธนาคาร

  1. ในแอปธนาคาร เปิดการส่งอีเมลแจ้งทุกรายการ และเพิ่มอีเมลนั้นในแอป Mail ของ iPhone
  2. เลือก อีเมล → ผู้ส่ง เป็นอีเมลของธนาคาร → รันทันที
  3. เพิ่มคำสั่ง เรียกใช้คำสั่งลัด → Dept บันทึก ข้อมูลเข้าเป็น ข้อมูลเข้าของคำสั่งลัด

ตอนนี้ระบบอ่าน SMS ของ KTC, CardX, ttb และ SCB ได้ ส่วนอีเมลอ่านได้: KTC (Onlineservice@ktc.co.th), CardX (support@cardx.co.th, เฉพาะยอดเป็นบาท) และ K PLUS ชำระค่าสินค้า (KPLUS@kasikornbank.com) อีเมลโอนเงินและเติมเงิน e-Wallet ข้ามไว้เพราะสลิปบันทึกให้แล้ว ธนาคารอื่นส่งตัวอย่างข้อความให้ผู้ดูแลเพื่อเพิ่มได้

4ลบของเก่าที่ไม่ใช้แล้ว

Scriptable ควรเหลือDeptInstaller, DeptWidget, DeptAuto
คำสั่งลัดควรเหลือDept บันทึก (ลบ "สแกนสลิป" และ "สลิปอัตโนมัติ" ได้)
การทำงานอัตโนมัติเหลือแค่แบบ A, B, C ที่ใช้ แต่ละอันมีคำสั่งเดียว (ของเดิมที่มีหลายคำสั่ง เช่น AutoSMS ลบแล้วสร้างใหม่ได้เลย)

5เช็กว่าเป็นรุ่นล่าสุด

ไม่ต้องเช็กเอง ถ้าเครื่องเป็นรุ่นเก่า ระบบจะเด้งแจ้งเตือน "มี DeptAuto รุ่นใหม่" ให้เปิด Scriptable แล้วกดรัน DeptInstaller อีกครั้ง คำสั่งลัดและการทำงานอัตโนมัติไม่ต้องแก้

แก้ปัญหา

จ่ายเงินแล้วไม่มีแจ้งเตือนอะไรเลย

ตรวจ (1) ตั้งค่า → การแจ้งเตือน → Scriptable → เปิดอนุญาต (2) การทำงานอัตโนมัติตั้งเป็น รันทันที (3) รันตัวติดตั้งล่าสุดแล้ว ระบบเงียบโดยตั้งใจเมื่อเป็นรายการเดิมที่บันทึกแล้ว รูปล่าสุดไม่ใช่สลิป หรือ SMS ไม่ใช่รายจ่าย (เช่น ยอด THB0, จ่ายบิลบัตร)

แตะแจ้งเตือนแล้วแอป Scriptable เปิดขึ้นมา

เป็นปกติ กล่องแก้ไขอยู่ในแอป Scriptable บันทึกเสร็จแล้วกลับไปแอปเดิมได้เลย ถ้ายังไม่ว่าง กด ไว้ทีหลัง รายการยังอยู่ในเว็บพร้อมป้ายยังไม่ยืนยัน

ยอดหรือชื่อร้านผิด

แตะแจ้งเตือน หรือเปิดเว็บแท็บ กระเป๋า แล้วแตะรายการเพื่อแก้ ถ้าผิดบ่อย ส่งข้อความ SMS หรือภาพสลิปให้ผู้ดูแล (ปิดเลขบัญชีได้) เพื่อปรับให้อ่านถูก

ขึ้นว่า "ยังไม่ได้ตั้งค่ารหัสอุปกรณ์" หรือ "รหัสไม่ถูกต้อง"

ทำขั้นที่ 1 ใหม่ (สร้างรหัสใหม่ แล้วรันตัวติดตั้ง) คำสั่งลัดไม่ต้องแก้
