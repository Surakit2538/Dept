ให้ iPhone บันทึกรายจ่ายเอง

4 ขั้น ประมาณ 5 นาที · ทำครั้งเดียว · ใช้กับ DeptAuto รุ่น 2.2.0 · อัปเดต 21 พ.ย. 2569

ทำทีละขั้นจากบนลงล่าง กด "ทำขั้นนี้แล้ว" เมื่อเสร็จแต่ละขั้น

ตั้งเสร็จแล้ว ใช้งานแบบนี้
  1. จ่ายเงินตามปกติ (โอนแล้วแคปสลิป หรือรูดบัตรแล้วมี SMS/อีเมล)
  2. iPhone เด้งแจ้งเตือน "พบรายจ่าย ..." แตะที่แจ้งเตือน
  3. แก้ชื่อหรือหมวดได้ แล้วกด บันทึกส่วนตัว หรือ หารกับเพื่อน

ไม่กดอะไรก็ได้ ระบบเก็บเป็นรายจ่ายส่วนตัวให้ (ในเว็บมีป้าย ยังไม่ยืนยัน) ชื่อที่แก้ ระบบจำไว้ใช้ครั้งหน้า

  • 1ติดตั้งแอป Scriptable (ฟรี) เปิด App Store
  • 2เปิดเว็บ Dept Money แท็บ ฉัน → ตั้งค่า iPhone → กด สร้างรหัสและคัดลอกสคริปต์
  • 3เปิด Scriptable กด + ลบข้อความเดิม แล้ว วาง จากนั้นกดปุ่ม เล่น (สามเหลี่ยมมุมขวาล่าง)
  • 4ขึ้น ติดตั้งสำเร็จ และเห็น DeptWidget กับ DeptAuto ในแอป
ติดตั้งสำเร็จ · DeptWidget, DeptAuto v2.2.0

ถ้ามีหน้าต่าง "พบสคริปต์ Dept ที่ไม่ใช้แล้ว" กด ลบทั้งหมด

ครั้งแรกที่ระบบเด้งแจ้งเตือน iPhone จะถามว่าให้ Scriptable แจ้งเตือนได้ไหม ให้กด อนุญาต

ดูทีละขั้น (7 ขั้น)
  • 1เพิ่ม ถ้า เลือก ข้อมูลเข้าของคำสั่งลัด → มีค่าใดค่าหนึ่ง (การ์ด "รับ ... จาก ไม่มีที่ไหน" ด้านบนโผล่มาเอง ไม่ต้องแก้)
  • 2ใต้ ถ้า: เพิ่ม Run Script ของ Scriptable เลือก DeptAuto ช่องหลังเลือก ข้อมูลเข้าของคำสั่งลัด แตะลูกศรท้ายแถว ปิด Run In App และ แสดงเมื่อสั่งทำงาน
  • 3ลากคำสั่งถัดไปมาไว้ใต้ มิฉะนั้น
  • 4รับรูปภาพล่าสุด จำนวน 1 และเปิด รวมภาพถ่ายหน้าจอ
  • 5แยกข้อความออกจาก รูปภาพล่าสุด
  • 6Run Script DeptAuto ช่องหลังเลือก ข้อความที่แยกออก ปิด 2 ตัวเลือกเหมือนข้อ 2
  • 7สิ้นสุดถ้า แอปเติมให้เอง ไม่ต้องใส่

  • 2การทำงานอัตโนมัติ → + → อีเมล → ผู้ส่ง เป็นอีเมลของธนาคาร → รันทันที
