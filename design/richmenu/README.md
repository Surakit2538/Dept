# Rich menu ของ LINE OA (Dept Money)

ไฟล์รูป: `richmenu.png` (2500 x 1686 พิกเซล ขนาดไม่ถึง 1 MB ตรงตามที่ LINE กำหนด) แก้ดีไซน์ได้ที่ `richmenu.html` แล้ว render ใหม่ด้วย Chrome:

```bash
chrome --headless=new --hide-scrollbars --force-device-scale-factor=1 --window-size=2500,1686 --virtual-time-budget=10000 --screenshot=richmenu.png file:///.../richmenu.html
```

## ตั้งค่าใน LINE Official Account Manager (หน้าจอที่เลือกเทมเพลตแล้ว)

เทมเพลต: **ใหญ่ แบบ 1 ช่องบน + 3 ช่องล่าง** (อันที่ไฮไลต์สีเขียว)

1. **ชื่อ:** Dept Money ช่วงที่แสดง: ตั้งวันสิ้นสุดให้ไกลๆ (เช่น ปีหน้า)
2. **รูป:** กดอัปโหลด เลือกไฟล์ `richmenu.png`
3. **แอ็กชัน** (กดเลือกทีละช่อง A B C D):

| ช่อง | ตำแหน่ง | ประเภท | ใส่ค่า |
|---|---|---|---|
| A | บน (ใหญ่) สรุปยอดเดือนนี้ | ข้อความ | `สรุป` |
| B | ล่างซ้าย เพิ่มบิล | ข้อความ | `เริ่มต้นจดบันทึก` |
| C | ล่างกลาง เคลียร์เงิน | ลิงก์ | `https://dept-game.vercel.app/#clear` |
| D | ล่างขวา เปิดเว็บ | ลิงก์ | `https://dept-game.vercel.app/` |

4. **ข้อความบนเมนูบาร์:** `เมนู` · **การแสดงเมนูแบบเริ่มต้น:** เปิดไว้ (แสดงเมนูทันที)
5. กด **บันทึก**

## ใช้ยังไง

- แตะ **สรุปยอดเดือนนี้** บอทส่งการ์ดสรุป (ใครค้างคุณ + ปุ่มเตือน) เหมือนพิมพ์ "สรุป"
- แตะ **เพิ่มบิล** บอทถามชื่อรายการทีละขั้น (ใช้ได้ในแชต; ถ้าอยากกรอกแบบฟอร์มเต็มให้แตะ **เปิดเว็บ** แล้วกดปุ่ม "บันทึกรายการ")
- รายรับ: พิมพ์ในแชตได้เลย เช่น `เงินเดือน 25000`

ถ้าเปลี่ยนคำสั่งของบอท ต้องแก้ค่าในตารางด้านบนให้ตรง (ข้อความต้องตรงทุกตัวอักษร)
