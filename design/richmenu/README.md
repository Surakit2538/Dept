# Rich menu ของ LINE OA (Dept Money) แบบ B: 4 ช่อง

ไฟล์รูป: `richmenu.png` (2500 x 1686 พิกเซล ประมาณ 0.5 MB ตรงตามที่ LINE กำหนด) แก้ดีไซน์ได้ที่ `richmenu.html` แล้ว render ใหม่ด้วย Edge หรือ Chrome:

```bash
msedge --headless=new --hide-scrollbars --force-device-scale-factor=1 --window-size=2500,1686 --virtual-time-budget=10000 --screenshot=richmenu.png file:///.../richmenu.html
```

## ตั้งค่าใน LINE Official Account Manager

เมนู **หน้าหลัก > Rich menu** แล้วแก้อันเดิม (หรือสร้างใหม่แล้วปิดอันเดิม)

1. **เทมเพลต:** กด "เลือกเทมเพลต" เลือก **ใหญ่ แบบ 4 ช่อง (2 x 2)**
2. **รูป:** กด "อัปโหลดรูปภาพ" เลือกไฟล์ `richmenu.png`
3. **แอ็กชัน** (กดเลือกทีละช่อง A B C D):

| ช่อง | ตำแหน่ง | ประเภท | ใส่ค่า |
|---|---|---|---|
| A | บนซ้าย สรุปเดือนนี้ (น้ำเงิน) | ข้อความ | `สรุป` |
| B | บนขวา เพิ่มบิล (ทานตะวัน) | ลิงก์ | `https://liff.line.me/2008948704-db2goT00#add` |
| C | ล่างซ้าย เคลียร์เงิน | ลิงก์ | `https://liff.line.me/2008948704-db2goT00#clear` |
| D | ล่างขวา เปิดเว็บ | ลิงก์ | `https://liff.line.me/2008948704-db2goT00` |

4. **ข้อความบนเมนูบาร์:** `เมนู` · **การแสดงเมนูแบบเริ่มต้น:** แสดง
5. กด **บันทึก**

## ใช้ยังไง

- แตะ **สรุปเดือนนี้** บอทส่งการ์ดสรุปแบบปัด (ภาพรวม, หมวด, รายสัปดาห์, ใครค้างคุณ + ปุ่มเตือน) เหมือนพิมพ์ "สรุป"
- แตะ **เพิ่มบิล** เปิดหน้าต่างบันทึกในเว็บทันที (บิลหารกับเพื่อน / รายจ่ายส่วนตัว / รายรับ)
- ใต้ข้อความของบอทมีปุ่มลัด: สรุปเดือนนี้, ใครค้างฉัน, ฉันต้องโอน, รอยืนยัน, วิธีใช้
- รายรับ: พิมพ์ในแชตได้เลย เช่น `เงินเดือน 25000` · รายจ่ายส่วนตัว: `กาแฟ 65`

**ทำไมใช้ลิงก์ liff.line.me:** LINE จะล็อกอินให้อัตโนมัติ ไม่ต้องกดล็อกอินทุกครั้ง (ลิงก์ dept-game.vercel.app ตรงๆ จะเด้งไปหน้าล็อกอิน)

ถ้าเปลี่ยนคำสั่งของบอท ต้องแก้ค่าในตารางด้านบนให้ตรง (ข้อความต้องตรงทุกตัวอักษร)

## รูปโปรไฟล์ของบอท

รูปวงกลมข้างข้อความบอทเป็นรูปโปรไฟล์ของ LINE OA (ยังเป็นโลโก้ dm เดิม) เปลี่ยนได้ที่ **ตั้งค่า > บัญชี > รูปโปรไฟล์** ใช้ไฟล์ `icons/icon-512.png` (โลโก้ใบเสร็จใหม่)
