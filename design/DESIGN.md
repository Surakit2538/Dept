# Dept Money — ระบบดีไซน์ (ทิศทาง A "สมุดบัญชี")

แหล่งข้อมูลสี/ฟอนต์/ขนาด: `design/tokens.json` (ห้ามฮาร์ดโค้ดค่าสีนอกไฟล์นี้) · อินโฟกราฟิกแสดงภาพรวม: ดูหน้า Brand Sheet ที่เจ้าของเก็บไว้

## 1. หลักการ

1. **ตัวเลขต้องอ่านผิดไม่ได้** — ตัวเลขเงินใช้ฟอนต์ mono ระยะเท่ากัน จัดชิดขวาในตาราง สีบอกความหมายเท่านั้น
2. **ความหมายเดียวต่อคำหนึ่งคำ** — ทุกหน้า (เว็บ Widget LINE) ใช้ศัพท์ในหัวข้อ 3 เหมือนกันทุกตัวอักษร
3. **เรียบ เส้นบาง** — เส้น hairline 1px แทนเงา พื้นผิวเรียบ ไม่ใช้ไล่สีเป็นพื้นหลัง
4. **สองโหมดเท่าเทียม** — สว่างและมืดออกแบบพร้อมกัน ใช้ token เสมอ
5. **อ่านบนมือถือก่อน** — ปุ่มสูงอย่างน้อย 44px ตัวหนังสือไม่เล็กกว่า 11px แถบนำทางมีตัวหนังสือกำกับทุกปุ่ม

## 2. โลโก้และสี

- โลโก้ = เหรียญทองลายดอลลาร์ (ไฟล์เดิมของเว็บ) วางคู่ชื่อ **Dept Money** ข้างขวา ช่องว่างรอบโลโก้อย่างน้อยเท่าครึ่งความสูงเหรียญ ห้ามเปลี่ยนสี ห้ามหมุน ขนาดต่ำสุด 24px
- **สีทองเหรียญใช้กับโลโก้และจุดเน้นเล็กเท่านั้น** (ขอบแถบหัวข้อ, ป้ายสรุป) ไม่ใช้เป็นสีปุ่มหรือสีตัวเลข
- สีใช้งานหลัก: เขียวอมฟ้า (`accent`/`receive`) = ได้รับ/ปุ่มหลัก · ส้มเข้ม (`pay`) = ต้องจ่าย/ใช้ไป
- ห้ามใช้สีแดงเขียวสดแบบสัญญาณไฟ; ห้ามใช้สีเดียวกันกับความหมายสองอย่าง

## 3. ศัพท์ตัวเลขกลาง (ใช้เหมือนกันทุกที่)

| คำ | ความหมาย | สี |
|---|---|---|
| **ใช้ไป** | รายจ่ายของฉัน = ส่วนตัว + ส่วนของฉันในบิลกลุ่ม | pay |
| **ส่วนตัว** | รายจ่ายที่บันทึกคนเดียว เพื่อนไม่เห็น | ปกติ |
| **ส่วนของฉันในกลุ่ม** | ส่วนที่ฉันต้องรับผิดชอบในบิลกลุ่ม (ไม่ใช่ยอดเต็มบิล) | ปกติ |
| **รายรับ** | เงินที่ฉันได้รับจริง (เงินเดือน ฯลฯ) **ไม่รวมเพื่อนโอนคืนหนี้** | receive |
| **ได้คืนแล้ว** | เพื่อนโอนคืนหนี้ให้ฉัน (แสดงแยก ไม่นับรายรับ) | receive |
| **โอนคืนแล้ว** | ฉันโอนคืนหนี้ให้เพื่อน (แสดงแยก ไม่นับรายจ่ายซ้ำ) | ปกติ |
| **เพื่อนค้างฉัน** / **ฉันค้างเพื่อน** | ยอดหนี้หลังหักที่เคลียร์แล้ว | receive / pay |
| **สุทธิ** | รายรับ − ใช้ไป (กระเป๋าของฉัน) | receive ถ้าบวก, pay ถ้าลบ |
| **เคลียร์แล้ว** | ยอดค้างต่ำกว่า 1 บาท | ปกติ |

ห้ามใช้คำว่า "ยอดรวม" โดยไม่บอกว่าของใคร; ห้ามโชว์ยอดเต็มบิลกลุ่มติดลบเหมือนเป็นรายจ่ายของฉัน

## 4. ตัวอักษรและตัวเลข

- ข้อความ: IBM Plex Sans Thai (สำรอง Noto Sans Thai) · ตัวเลขเงิน: IBM Plex Mono, `font-variant-numeric: tabular-nums`
- ขนาด: 11 / 13 / 15 / 18 / 24 / 34 (display ใช้เฉพาะยอดหลักหนึ่งตัวต่อหน้าจอ)
- ตัวเลขหลัก (สุทธิ, หนี้) ปัดเป็นบาท; รายการและรายละเอียดแสดงทศนิยม 2 ตำแหน่ง; สัญลักษณ์ `฿` นำหน้า ไม่มีเว้นวรรค

## 5. ส่วนประกอบ

- **การ์ด:** พื้น `surface` + เส้น `line` 1px, มุม `md` (8px)
- **ปุ่มหลัก:** พื้น `accent` ตัวอักษร `accentInk` · **ปุ่มรอง:** โปร่ง เส้น `line` · สูง ≥ 44px
- **ชิป (ธนาคาร/ประเภท):** พื้น `chip` มุม `sm` ตัวเล็กตัวหนา
- **แถบนำทางล่าง:** 5 ปุ่ม มีไอคอนเส้น + ตัวหนังสือ: หน้าแรก · บิล · เคลียร์เงิน · กระเป๋า · ฉัน
- **รายการหนี้:** ชื่อ + คำอธิบายเล็ก ชิดซ้าย, ยอดชิดขวา (mono), ปุ่ม "โอน" เฉพาะเมื่อฉันเป็นฝ่ายค้าง

## 6. การใช้ต่อพื้นผิว

| พื้นผิว | กติกา |
|---|---|
| **เว็บ** | ใช้ token ผ่าน Tailwind config; โครงหน้าตามหัวข้อ 5 |
| **Widget** | ใช้ขนาด/สีตาม token (เขียนค่าใน `DeptWidget.js`); แถวบน: ชื่อแอปตัวเล็กห่างตัวอักษร + วันที่; ตัวเลข 2 ช่องคั่นเส้นบาง; ล่างสุด: รายการล่าสุดหรือสถานะหนี้ |
| **หน้าต่างสแกนสลิป** | ชื่อ "พบบิลใหม่" → ยอดใหญ่ (mono) → ธนาคาร/ผู้รับ/วันที่ → ปุ่ม: บันทึกส่วนตัว · หารกับเพื่อน · ปิด (ภาษาเดียวกับศัพท์กลาง) |
| **การแจ้งเตือน** | หัวข้อ = ผลลัพธ์สั้นๆ ("บันทึกส่วนตัวแล้ว ฿1,084.97") บรรทัดสองบอกรายละเอียด (ชื่อรายการ · ธนาคาร · วันที่) ไม่มี emoji นำหน้า |
| **LINE** | การ์ดหัวสี `accent`, ตัวเลขหลัก mono, แถวหนี้ชื่อซ้าย/ยอดขวา, ปุ่มเดียวเปิดหน้าเคลียร์เงิน |

## 7. ข้อห้ามสั้นๆ

- ห้ามเพิ่มสีใหม่ที่ไม่อยู่ใน `tokens.json`
- ห้ามใช้ emoji เป็นไอคอนหลักหรือเครื่องหมายหัวข้อ
- ห้ามแสดงยอดกระเป๋าส่วนตัว (รายรับ/ส่วนตัว) ในข้อความหรือรายงานที่ส่งเข้ากลุ่ม
- ห้ามฝังข้อความจากผู้ใช้/สลิปเป็น HTML ดิบ ใช้ `textContent` เสมอ
